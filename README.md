# 番茄小说下载器

这是一个基于 Python Flask 和 Web 技术的番茄小说下载工具，允许用户通过简单的网页界面下载指定小说并保存为 `.txt` 文件。

## 主要功能

- **网页界面**：提供一个美观、易于使用的界面，用户只需粘贴小说 URL 即可开始。
- **范围或全部下载**：支持下载指定章节范围，或一次性下载全部章节。
- **反内容混淆**：能够自动处理番茄小说网页中的文字混淆，将特殊编码的字符还原为正常文本。
- **实时进度反馈**：下载过程中，页面会实时显示进度条和当前下载状态。
- **验证码处理**：当遇到人机验证时，程序会提示用户，并提供一个链接在新标签页中完成验证，提高了下载的成功率。
- **SVIP Token 支持**：用户可以提供自己的 `sessionid` Token 来绕过验证码或下载 VIP 章节。

## 技术栈

- **后端**：Python, Flask
- **前端**：HTML, CSS, JavaScript
- **爬虫库**：`requests`, `parsel`

## 安装与运行

1.  **克隆或下载项目**

2.  **安装依赖**

    确保你已经安装了 Python 3。然后通过 pip 安装所需的库：
    ```bash
    pip install Flask requests parsel
    ```

3.  **运行应用**

    进入 `fanqie2txt` 目录，并运行 `app.py`：
    ```bash
    cd fanqie2txt
    python app.py
    ```

4.  **访问应用**

    打开你的浏览器，访问 `http://127.0.0.1:8080`。

## 使用说明

1.  将番茄小说的目录页 URL 粘贴到输入框中。
2.  （可选）如果需要，可以填入你的 SVIP Token (`sessionid`)。
3.  选择要下载的章节范围，或点击“下载全部”。
4.  等待下载完成，文件将自动保存到你的电脑上。
5.  如果提示需要验证码，请点击提供的链接，在新打开的页面中完成验证，然后返回下载器页面重新尝试下载。
